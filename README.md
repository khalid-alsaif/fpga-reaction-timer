# FPGA Reaction Timer

**[Download the complete prepared project](project-source.zip)** — extract this archive to restore the original project folder structure. Key source and report files are also available below for browsing.

A Verilog reaction-timer project with display logic, timing generators, and supporting digital modules.

## Technologies

Verilog / Xilinx ISE

## Explore the project

Inspect ReactionTimer.v and the related modules. Open the supplied ISE project if available. Hardware configuration and constraints must be checked before programming a board.
